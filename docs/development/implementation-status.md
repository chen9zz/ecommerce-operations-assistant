# 当前实施与验证状态

日期：2026-10-03。交付是可运行的本地首版，不再只是设计报告。

## 已落实

规则引擎、真实API编排、SQLite持久化、原文证据、缺失条件追问、历史快照恢复、反馈、中文四页工作台、20条模拟业务评测、LightRAG SDK适配和真实SDK冒烟脚本。

## 验证口径

自动测试覆盖促销金额/身份/标签/有效期边界、API输入和源校验、持久化恢复、检索错误与不回退、证据版本校验、索引状态与独占锁、评测失败可见性。最终测试数和浏览器结果以 verification.json 为准。

SDK检查实际构建临时索引，通过真实 `ainsert_custom_kg` 与 `aquery_data(mode='mix')` 得到12个实体、6条关系、6个chunk，并映射到R1–R6。模型使用测试替身、相似度阈值用于充分检查管道，不代表模型准确率、召回率或论文复现成绩。

20条业务评测使用自建固定规则和显式期望值，记录逐例输入、状态、推荐、金额及延迟。低延迟只反映本地词法路径，不代表接入模型后的p95。

## 工程取舍

原报告曾建议PostgreSQL；本机单店首版改用SQLite，便于无需数据库服务运行，接口分层允许后续替换。前端使用原生JavaScript而非独立构建链，减少演示部署步骤。没有LLM密钥时使用显式词法演示模式；真实SDK接入独立验证，不伪装成已接入真实模型。
